HealthSwitchLive demo Connecting…

One switch, six separate websites

Each website below belongs to a different organisation and has its own login. Open them in separate tabs and place them side by side: a request sent from a hospital appears in the HMO’s inbox a few seconds later, after passing through the HealthSwitch gateway and message queues. All organisations, people and amounts are fictional.

Enter the demo access key

You need it once on this browser. The logins for each website appear after it.

Suggested demo, about 10 minutes

  1. PalmgroveSign in. Open New request, check cover for Tunde Bakare (Northstar HMO), tick consent and send a consultation plus full blood count.
  2. Switch consoleWatch the message pass through q.route and q.deliver.portal. Open a log row to show the envelope and FHIR payload.
  3. Northstar HMOThe request is in the Review inbox. Approve the consultation, choose Request info on the blood count with a note, add a remark and submit.
  4. PalmgroveThe query and remark appear. Upload any PDF or photo and send it.
  5. Northstar HMOThe document is back in the inbox. View it and approve.
  6. PalmgroveSubmit the final claim. Northstar HMOApprove it, then in Payments batch Palmgrove’s claims and simulate the payment. Palmgrove’s Payments tab shows them as paid.
  7. RiversideSend a consultation for Emeka Nwosu (Sapphire HMO). Sapphire’s own system decides it in seconds because it is under ₦50,000.
  8. RiversideSend another for Emeka with an MRI. It is over ₦50,000, so it lands in Sapphire HMO’s reviewer inbox. Decide it there.
  9. Point out that Riverside never sees Palmgrove’s patients, and Northstar never sees Sapphire’s claims.
  10. Switch consoleTurn Sapphire HMO offline, send a Sapphire request from Riverside, watch it retry, then turn Sapphire back on and watch it deliver.
  11. Regulator viewNational totals, approval rates and payment ageing, with no patient-level data.

Before a meeting: open this page a minute early (the free server sleeps when idle), then use Reset demo data in the switch console for a clean start.
